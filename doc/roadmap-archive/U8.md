# U8 — Logs tab: clickable script prefix opens the script in the editor ✅ implemented
*Archived roadmap item — Web UI & Editor. Open items: [../../ROADMAP.md](../../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Implemented.** In `web/src/pages/Logs.svelte`, log lines whose message carries a script-label prefix (e.g. `licht/hobbyraum.js: …`, matched with the same `/^([^:\n]+\.js):\s/` pattern the Scripts tab uses for log routing) render the prefix as a clickable, brand-colored link. Clicking it sets `location.hash = 'scripts'` (existing hash navigation switches the tab) and dispatches a `she:open-script` CustomEvent with the path; `Scripts.svelte` listens on `window` (all pages stay mounted, so the listener is always live) and opens/focuses the file through its existing `openTab()` logic, including log-history seeding.

**Deliberately not done here:** the stable `#/scripts/<path>` deep-link route. The internal event was the smaller change; the public deep-link URL remains an [I3](../../ROADMAP.md#i3--feezal-dashboard-pairing) work item (feezal "open adapter in she" links) and can replace the event mechanism when it lands.
