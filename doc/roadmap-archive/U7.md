# U7 — Hide the log panel when no file is open in the Scripts tab ✅ implemented
*Archived roadmap item — Web UI & Editor. Open items: [../../ROADMAP.md](../../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Implemented.** The per-script log panel (including its resize handle and collapse toggle) in `web/src/pages/Scripts.svelte` is now rendered only while at least one editor tab is open (`{#if tabs.length > 0}` around the `.log-panel` block). The persisted open/closed state (`she-log-open`) and height (`she-scripts-log-height`) are untouched — they apply again as soon as the first tab opens.

**Original item:** the panel was shown even with no editor tab open, where it could only ever be empty (it displays the active tab's `logEntries`).
