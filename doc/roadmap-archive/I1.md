# I1 — Expose influx config options in the Config UI ✅ implemented
*Archived roadmap item — Integrations. Open items: [../../ROADMAP.md](../../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Implemented.** The Config page (Settings → InfluxDB) now exposes the `influx` config block: URL, API version switch, and the version-specific fields — token/org/bucket for 2.x, database/username/password for 1.x (see [I2](I2.md)). Leaving the URL empty disables the integration; changes require a daemon restart (like all non-frontend config keys). `influx` was added to the Config page's known keys so the block round-trips cleanly through save.

**Original item:** the InfluxDB connection settings (`--influx` daemon config: url, token/credentials, org, bucket, …) were only configurable via CLI flags / `config.json`. Add an InfluxDB section to the Config page so they can be viewed and edited in the web UI, consistent with how the MQTT broker settings are exposed.

**Relates:** [I2](I2.md) ✅ (v1 compatibility — the version switch in this UI).
