# U9 — Log views: show milliseconds in timestamps ✅ implemented
*Archived roadmap item — Web UI & Editor. Open items: [../../ROADMAP.md](../../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Implemented.** New shared helper `fmtLogTs()` in `web/src/lib/format.ts` renders `HH:MM:SS.mmm` (24 h, e.g. `12:13:14.567`). All three log views import it instead of their previously divergent local `fmt()` copies: the Logs tab (`Logs.svelte`, was second-resolution `toLocaleTimeString()`), the log panel in the Scripts tab (`Scripts.svelte`, was `toLocaleTimeString` without ms), and `broker/MosquittoLogs.svelte` (already had ms — its format became the shared one).
