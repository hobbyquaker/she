# I10 — Services: edit adapter files (map files & co.) ✅ implemented
*Archived roadmap item — Integrations. Open items: [../../ROADMAP.md](../../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Implemented (she 1.26.0), filed and built in one step.** The instance drawer's new **Files** tab edits the files an adapter instance maintains — cul2mqtt's map file being the first case — in Monaco with validation.

- **How she knows the files** (decided in the discussion that preceded this item): (1) the adapter declares file options — mqtt-interfaces-core 0.6.0 adds `file: {format, example, schema, describe}` on an option definition → `"x-file": {…}` in `--config-schema`; cul2mqtt 1.1.2 declares `--map-file` (json, `example-map.json`, new `map.schema.json`); (2) for older adapters a heuristic: string options named `…-file`/`…-path`/`…-map` whose value has a known extension; (3) a listing of `/etc/<adapter>/` and `/var/lib/<adapter>/<instance>/` (one level deep, no dotfiles). `mqttInterfaces.files` in package.json was rejected — the option carries the path, keeping the metadata next to it avoids drift.
- **Helper v3** (`service/she-servicectl`): `files`, `file read|write <path>` (realpath must be inside the two managed directories; temp + rename, `.bak`, owner/mode kept or `0640 root:<adapter>` for new files), `asset <relpath>` (a file shipped in the adapter package, realpath inside the package dir). Verified on mqtt-ifaces.
- **API** ([src/web/services-api.js](../../src/web/services-api.js)): `GET …/files` (options with `managed`/`exists`, listing with `format`/`editable`), `GET/PUT …/file` (path checks, 2 MB cap, env file refused), `POST …/file/create` (from example or empty at `/etc/<adapter>/<instance>.<option>.<ext>`, sets the option), `GET …/adapters/:adapter/asset`.
- **Frontend**: `InstanceFiles.svelte` — list of file options (format badge, declared/guessed, missing → *Create from example*, outside the managed dirs → hint) plus the directory listing; Monaco with language by format; JSON validated against the adapter's schema when it ships one (registered per model in `MonacoEditor.svelte`, which gained `jsonSchema`, `markers` and `onMarkers`), YAML linted with js-yaml (error markers); problem counter, *Save* / *Save & restart*, Ctrl-S.
- **Tests**: `fileOptions()` (declared + heuristic, managed vs outside), listing, read/write with path refusals, asset, create-from-example (env updated).
- **Docs**: services.md (Files paragraph, helper commands, adapter-author step 4), http-api rows, security note.
